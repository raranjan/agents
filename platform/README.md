Shared platform SDK for AgentStack agent services.

Python package: `agentstack` (import via `PYTHONPATH=platform:.`).

- `agentstack.config` — environment settings
- `agentstack.models` — shared Pydantic models
- `agentstack.logging` — structured logging setup
- `agentstack.sdk.llm` — `LLMClient` protocol
- `agentstack.sdk.prompts` — file-based prompt loading
